# Задача: сборка чистового русского EPUB из переведённых чанков (для любого тома N)

Работаем с GitHub-репозиторием `PikaWarrior/SukaMoka` и/или прикреплёнными файлами русского перевода.

**Цель: собрать валидный, перестраиваемый (reflowable) русский файл `SukaMoca_vN_ru.epub` для целевого тома N без переноса старой японской фиксированной вёрстки и шрифтов.**

## 1. Входные данные для тома N
1. **Русский текст:** переведённые файлы чанков (`chunk_01.md` … `chunk_XX.md`) или объединённый русский Markdown-файл тома N.
2. **Карта ресурсов и структуры:** файл отчёта `volumeN_report.md` (или `completed_volumes/volumeN_report.md`) и исходный каталог изображений `raw/N/item/image/`.
3. **Запрет на вкусовую редактуру:** при сборке EPUB **не переписывай** и не «улучшай» русский литературный перевод. Разрешены только технические операции сборки, описанные ниже.

## 2. Обязательная предобработка текста перед упаковкой в EPUB
1. **Проверка порядка чанков и глав:** убедись, что все переведённые чанки от `chunk_01` до последнего идут строго по порядку следования в `volumeN_report.md` (по `spine` исходного тома), без пропущенных или продублированных подразделов `##` и `###`.
2. **Сквозная перенумерация сносок (`[^1]` … `[^K]`):**
   Поскольку в каждом отдельном чанке нумерация сносок начинается с `[^1]`, при объединении чанков в том **обязательно перенумеруй все сноски сквозным образом** (`[^1]`, `[^2]` … `[^K]`) или привяжи их к главе (`ch1-fn1`), чтобы ссылки `[^1]` из разных чанков не конфликтовали! Оформи их в EPUB как корректные кликабельные сноски (с возвратом к тексту или `epub:type="noteref"` / `footnote`).
3. **Обработка маркеров `[[EPUB_IMAGE:...]]`:**
   Сверь каждый маркер в русском тексте с таблицей «Карта размещений изображений» в `volumeN_report.md`:
   — **Разделители сцен (`gaiji-cid776` и аналогичные одиночные маркеры `gaiji` на отдельной строке между абзацами):** замени в XHTML на аккуратный центрированный текстовый разделитель `<p class="scene-break">* * *</p>`. Не вставляй растровую картинку вертикального японского разделителя.
   — **Полностраничные иллюстрации, обложка и кутиэ (`cover.jpg`, `kuchie-...`, `p004-005.jpg` и т. д.):** подтяни оригинальные графические файлы из `raw/N/item/image/<filename>`, включи их в `manifest` EPUB и вставь в соответствующие места XHTML. Обложку (`cover.jpg`) и цветные вклейки (`kuchie-*.jpg`) помести в начало `spine` перед титульным листом и текстом.
   — **Внутристрочные `gaiji`:** убедись, что в тексте не осталось нераскрытых сырых маркеров `[[EPUB_IMAGE:...]]` или служебных меток `[пауза]`.

## 3. Профиль вёрстки и CSS (Reflowable EPUB 3)
Не копируй издательские CSS KADOKAWA (`book-style.css`, `fixed-layout-jp.css`, `vrtl` и т. д.). Создай один чистый, лёгкий CSS-файл со следующими параметрами:
* **Ориентация и поток:** стандартный горизонтальный перестраиваемый текст (`reflowable`, `writing-mode: horizontal-tb`), выравнивание по левому краю (`text-align: left`), без красной строки (`text-indent: 0`), автоматические переносы отключены (`hyphens: none`).
* **Типографика:** шрифт без засечек (`font-family: sans-serif;`, без жёсткого встраивания тяжёлых шрифтовых файлов), базовый размер текста `1.125em`, межстрочный интервал `line-height: 1.5`. Цвета текста и фона жёстко не фиксировать (чтобы работали ночная и сепия-темы читалок).
* **Отступы:** отступ между абзацами и репликами `margin: 0 0 0.7em 0`; небольшой верхний отступ перед первым абзацем после заголовка `0.6em`; без широких боковых полей.
* **Заголовки (`##` и `###`):** полужирные, умеренного размера (`1.3em` для `h2`, `1.15em` для `h3`), номер и название в одну строку. Крупные части (`##`) начинать с новой страницы/XHTML-файла.
* **Разделители сцен (`.scene-break`):** центрированные `* * *` (`text-align: center; margin: 1.2em 0;`).
* **Иллюстрации:** адаптивные (`max-width: 100%; height: auto; display: block; margin: 1em auto;`), чтобы не обрезались на экранах любого размера.
* **Навигация:** сгенерировать рабочее оглавление EPUB 3 (`nav.xhtml` + при необходимости `toc.ncx` для совместимости со старыми читалками) по всем главам `##` и подразделам `###`.

## 4. Проверки после сборки
1. Ни один маркер `[[EPUB_IMAGE:...]]` или `[пауза]` не остался в видимом тексте книги.
2. Все сноски имеют уникальные ID и открываются корректно.
3. Все файлы иллюстраций, объявленные в `manifest`, физически присутствуют внутри архива `.epub`, а файл `mimetype` лежит первым и несжатым (`ZIP_STORED`).
4. Выдай готовый собранный файл `.epub` (или сохрани/обнови скрипт сборки) и краткую сводку проверки: количество глав, иллюстраций и сносок.
