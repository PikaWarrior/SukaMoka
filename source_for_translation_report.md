# Отчёт об извлечении XHTML для перевода

## Источники и полнота

Локальных вложений в сессии не было. Источник — EPUB-комплект тома 11 в репозитории `PikaWarrior/SukaMoka`, каталог `raw/11/item/`. Прочитан `standard.opf`; порядок ниже взят из `spine` с сопоставлением `idref` и `manifest`, не из сортировки имён.

Обработан полный XHTML-комплект spine тома 11: **27 из 27** ссылок разрешились. Это не фрагмент книги. Однако текст, существующий только внутри графических файлов, не извлечён; все такие изображения отмечены в исходнике. Оригинальные входные файлы не менялись. Результаты записаны в отдельную ветку `chatgpt/source-for-translation-vol11`, не в `main`.

## Преобразования

- Извлекался `body`; служебные `head`, CSS, скрипты, комментарии и метаданные не включались.
- `ruby/rt` преобразованы в `основа〔чтение〕`; сегменты с несколькими `rt` оставлены раздельными. Исходные чтения не исправлялись.
- `em-sesame` преобразован в `<em>…</em>`. Оболочки оформительских `span` (`tcy`, `line-break-loose`, `word-break-break-all` и размерный класс) сняты с сохранением их содержимого.
- Абзацы разделены пустыми строками; дополнительные пустые абзацы с `br` представлены как `[пауза]`.
- Графические заголовки извлечены из атрибутов `title` на страницах разделов и сверены с navigation-документом. Каждый из шести таких заголовков встречается в исходнике один раз; `あとがき` тоже оформлено как заголовок и не было скопировано из оглавления.
- Графические файлы не просматривались визуально в этой обработке. Для всех 17 изображений из manifest есть ровно по одному маркеру в соответствующем месте. Для `t001.jpg`–`t006.jpg` текст заголовка извлечён из XHTML; остальной возможный текст внутри изображений не извлечён.

## Проверки

- Структурно разобраны все 27 XHTML; несопоставленных закрывающих и незакрытых тегов не обнаружено.
- Текстовый слой без `rt` сопоставлен с исходным в порядке spine после снятия только согласованного оформительского отступа и служебных оболочек: **3 169 из 3 169 непустых абзацев совпали в исходном порядке**.
- В исходнике: **3 321** элемент `ruby` и **4 587** элементов `rt`. Все 4 587 чтений в итоговом файле совпали с оригиналом посимвольно и в исходной последовательности. В исходном тексте вне `rt` символы `〔` и `〕` не встречались; дополнительная пара в начале файла — только поясняющий пример.
- Сохранено **258** дополнительных пустых отбивок `[пауза]`; создано **30** Markdown-заголовков.
- Учтены **17/17** изображений из image manifest; ни один файл изображения не был заменён символом по одному лишь имени.
- Неразрешённые сложные структуры ruby не обнаружены. Но текст на изображениях остаётся непроверенным и не входит в текстовую сверку.
- Итоговый Markdown — около **148 400 единиц UTF-16** по длине строки JavaScript. Количество токенов не указывается: токенизатор целевой модели не задан.
