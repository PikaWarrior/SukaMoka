# Паспорт проекта: японское ранобэ → русский перевод
Версия: 1.5 (Актуально на: 19 октября 2026 года)

## Распределение ролей (Workflow: Gemini + Perplexity)
1. **Gemini (основной инструмент):** выполняет художественный перевод с японского по сценам, первично реконструирует сбои OCR, проводит самопроверку по чек-листу и вносит утверждённые правки.
2. **Perplexity (вторичный аудитор и сборщик):** выполняет финальную независимую сверку с оригиналом, вносит остаточные точечные правки по согласованию и компилирует файл `.epub` по профилю из этого паспорта.

## Как использовать
Прикрепить этот файл в новом чате вместе с текущим японским исходником и русским переводом. Первое сообщение: «Продолжаем проект по паспорту. Используй его как актуальные инструкции; при необходимости обновляй паспорт по правилам внутри». Перед работой ассистент проверяет фактически приложенные файлы; если нужный файл не прикреплён — запрашивает его у пользователя.

## Задача и стиль
Проект: перевод SukaSuka / SukaMoca с японского на русский (текущий том: 4 SukaMoca).
Стиль: бережная литературная передача на естественном русском языке без необоснованного расширения смысла. Сохранять юмор, недосказанность, внутреннюю перспективу, намеренные повторы и обрывы, различия между речью, мыслью и повествованием. Удачный текст не переписывать ради вкусовщины.

## Работа с источником и OCR
Пользователь извлекает текст из PDF (встречается битый OCR и вынесенная между строк фуригана). Другого исходника или сканов нет и не будет — не запрашивать их и не блокировать из-за этого выпуск перевода или EPUB.
— Очевидные сбои OCR восстанавливать самостоятельно по грамматике, контексту и повторениям; фуригану связывать с базовым словом (она может задавать важное чтение).
— При равных вариантах выбирать чтение с меньшим числом додуманных деталей, не заполняя пробелы спойлерами из следующих томов.
— Действительно тёмные места (OCR, новый термин, двусмысленность) кратко выносить после перевода в единый необязательный блок «Вопросы» (не смешивая его с художественным текстом). Мелкие очевидные исправления OCR не перечислять.

## Регламент команд для Perplexity
— **«Проверь»:** проанализировать текст (сначала японский смысл и OCR, затем глоссарий, затем русский язык) и предложить исправления (японская цитата → русский фрагмент → причина → минимальная замена), не меняя основной файл.
— **«Примени»:** точечно внести утверждённые правки в актуальный Markdown, проверив согласование форм в изменённых предложениях и не открывая новый круг вкусовой редактуры.
— **«Собери/пересобери EPUB»:** собрать `.epub` из актуального текста без переписывания перевода. Проверить структуру XML/XHTML, manifest/spine, оглавление, порядок глав и полное совпадение текста с Markdown (удалив служебные метки цитирования).

## Закреплённые правила перевода и редактуры
— **Пунктуация диалогов:** различать речевую ремарку («— Да, — ответил он.») и самостоятельное описание действия («— Я так и думал. — Магомедали почесал затылок.» либо с нового абзаца без тире).
— **Модальность и усилители:** не превращать догадки (だろう / ようだ / そうだ) в факты; не добавлять от себя «необратимо», «навсегда», «гарантированно», точное время, числа и направления.
— **Закреплённые решения по главам 4–7 и 1–3:** `90番台` = номера 90–99; вопрос к Спаде о языке = в отрицательной форме; `義兄` у Феодора к Одетте = «твой муж»; `一振り` = «Один из древнейших реликтовых клинков» (предмет, не взмах); `束ねられた願いを束ねたもの` = «То, что соединило воедино уже собранные желания»; `自覚できない` у Айсеи = «не осознавала»; `甘えん坊` = поиск тепла/ласки («ищем, к кому бы прижаться и кто бы нас приласкал»); `技官` у Айсеи = «наш техник» / «технический офицер»; `鍵` = «замок» (снятие ограничений) и «ключ» (условие запуска); реквизиты послесловия 2017 г. = `sukasuka-anime.com` и `@sukasuka_anime`.

## Профиль оформления EPUB (для сборки в Perplexity)
— Перестраиваемый текст (reflowable), выравнивание по левому краю, без красной строки, автоматические переносы отключены.
— Шрифт без засечек (sans-serif, без жёсткого встраивания), базовый размер ~1,125em, межстрочный интервал 1,5.
— Отступ между абзацами и репликами ~0,7em; небольшой верхний отступ перед первой строкой главы ~0,6em; без широких боковых полей и без фиксации цвета текста/фона.
— Заголовки глав: полужирные, умеренного размера, номер и название в одну строку.
— Разделители сцен: центрированные `* * *` с отступами сверху и снизу.
— Рабочее оглавление, сохранение курсива, удаление технических меток цитирования.

## Правила обновления паспорта (Строгий фильтр)
**НЕ обновлять паспорт** и не менять его версию после рядовой вычитки, исправления опечаток OCR или сборки очередного EPUB. Выдавать обновлённый файл паспорта **только** тогда, когда изменились глобальные переносимые данные: добавился новый термин/имя в глоссарий, появилось новое общее правило перевода или полностью завершилась работа над крупной частью тома.
Раздел «Журнал» (changelog) не вести и не восстанавливать — поддерживать только актуальное состояние в разделе «Текущий статус». При изменении глоссария синхронизировать короткий промпт Gemini.
